    Which tools voice chat/practice can call to look things up. Only applies to tools that are actually configured above.

    Outlook email (Microsoft 365 connector)

    Reads recent Outlook mail via the Microsoft 365 connector already configured for the claude CLI (claude mcp login, done once outside Speako). No client ID or token setup needed here — Speako fetches recent emails automatically in the background.

    Teams (Microsoft 365 connector)

    Reads recent Teams chat messages via the same Microsoft 365 connector as email above — no separate setup needed. Checked automatically in the background (see status below) as well as on demand — new messages get triaged and prioritized onto the Dashboard's Teams tab, with a drafted reply for anything directed at you. Replying still happens by hand (copy the drafted text into Teams yourself) — the connector can read Teams chats but can't send to them.

    Calendar import

    Auto-creates a Speako session (with prep already running) for every upcoming meeting in your current Outlook calendar week — see the calendar view (icon in the header), which has its own "Sync now" button. Reads via the same Microsoft 365 connector as email sync above.

    Communications indexing

    Chunks + embeds whatever's arrived in external_messages since the last run — from the email/Teams connector syncs above, or a separate daily ingestion task (see docs/EXTERNAL_INGESTION_PROMPT.md) for sources without native support.
