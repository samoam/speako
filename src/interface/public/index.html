    Voice chat tools

    Which tools voice chat/practice can call to look things up. Only applies to tools that are actually configured above.

    Microsoft Graph (Outlook / Teams)

    One-time setup: register an Azure AD app, set the client ID below, then run npm run msgraph-auth to sign in (see NOTES.md). Once signed in, Speako fetches recent emails and Teams chat messages automatically in the background.

    Outlook desktop (fallback)

    For mailboxes Microsoft Graph can't reach (hybrid/on-premises Exchange, or accounts that turn out to be B2B guests) — reads mail via classic desktop Outlook's own connection instead. Requires classic Outlook (not "New Outlook") on Windows. Manual only, not polled: Outlook may show a one-time security prompt to approve when you click Sync.

    Calendar import

    Auto-creates a Speako session (with prep already running) for every upcoming meeting in your current Outlook calendar week — see the calendar view (icon in the header). Unlike the Outlook desktop sync above, this one is polled unattended; Outlook may still show a one-time security prompt the first time it runs in a session.

    Communications indexing

    Chunks + embeds whatever's arrived in external_messages since the last run — from the Microsoft Graph sync above, or a separate daily ingestion task (see docs/EXTERNAL_INGESTION_PROMPT.md) for sources without native support.
